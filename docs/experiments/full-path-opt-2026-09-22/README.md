## 修改与解释

- `OpenNoSync`在Darwin也关闭扩容同步；默认同步存储不变。4KB页未显示稳定收益，恢复原生页。
- 成员进度查询只检查Approval是否存在，避免重复解码完整交易。它不再顺带检查该JSON正文是否损坏；金额审计继续完整读取。
- 网关对同一请求编码一次、复用只读字节向四成员发送；成员HTTP入口只解码验证一次。接收端独立认证、输入/预算事务、提交后签名不变。
- 新增显式 `bench-v4 -wallet-no-sync`（默认false），本轮收益包含放弃钱包同步刷盘与Darwin扩容同步；正常运行仍等待事务返回，不保证崩溃恢复。委员会Comet内存库、成员NoSync本来就是实验配置，不能将结果称为完整持久系统性能。
- 描述符成功缓存的微基准收益没有转化为稳定整机收益，已从工作源码移除，实验代码和测试另存为txt。
- 节奏器仍只保留四次发送信用。诊断记录的丢弃虚拟时间与发送跨度超出理论时长接近；这解释发送节奏变化的账目，不单独证明底层停顿来源。
