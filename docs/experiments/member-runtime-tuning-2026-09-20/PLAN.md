# 成员运行时优化：已批准执行的实验计划

只给成员进程改变运行时参数，委员会、网关、钱包及二进制保持一致。
保留三票、全部验签、同步持久化、10/10 ms 传播和现有重试规则。

1. 新创世、100 笔最终 UTXO、64 闭环并发，关闭诊断。交错运行四组各三次：
   A=GOMAXPROCS16/GOGC100；P4=4/100；P2=2/100；G200=16/200。
   顺序 A,P4,P2,G200 / G200,P2,P4,A / P4,A,G200,P2。
2. 每轮检查 100 笔成功、四委员状态相同、本金/费用、缺口和所有 outbox。
   对比快速到账 P50/P95、发完时间、闭环时间；同频率采样各进程 RSS 和累计 CPU 时间。
3. 有稳定收益的单项再独立确认、补阶段诊断，必要时验证组合；无收益的不保留。
4. 最佳候选与基线做持续发送对照，检查延迟、发送反压、在途量与内存随时间变化。
   100 笔短跑的 GC 收益不能代替持续运行验证。
5. 重复编解码仅在分配证据支持时改动；保持验证语义与不可变数据隔离，不增加缓存框架。

本轮先用标准环境变量和实验成员启动包装器。常驻高度 7 网络暂时停止，实验结束恢复其原数据。
不把实验中的最优参数写死为所有部署的默认值；最终是否采用取决于对照结果。

## 执行结果

已完成 16 轮无埋点短测、2 轮诊断、2 轮三分钟持续发送，共审计 12,602 笔。
选择本机成员 16/200，拒绝降低并行度，已经在保留原状态的常驻网络启用。
